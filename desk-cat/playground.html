Things to try
  • Move the pointerThe eyes follow it and the head tilts.
  • Hover gently over its headThat's petting. Hearts appear.
  • Drag the boxThe cat rides along.
  • Click the catIt jumps out. Click the box to call it back.
  • Keep the pointer near it, then hold stillIt crouches, wiggles and pounces.
  • Swipe fast right past itIt ducks, or runs home spooked.
  • Drag the catYou pick it up by the scruff. Drop it on the box.

Run the real app: download it

  1. On GitHub, open the repo's Actions tab and choose the latest DeskCat macOS build run.
  2. Under Artifacts, download DeskCat-app, then unzip it (twice) to get DeskCat.app.
  3. The app isn't signed with an Apple Developer ID yet, so macOS blocks the first launch. Clear that once in Terminal:
xattr -dr com.apple.quarantine ~/Downloads/DeskCat.app
open ~/Downloads/DeskCat.app

The cat appears near the bottom-right of your screen. Quit it from the cat icon in the menu bar.

Or build it yourself

  1. Install Apple's command line tools once: xcode-select --install
  2. Get the code from the branch claude/intelligent-noether-dt656x.
  3. Run it:
cd desk-cat
swift run

To keep it as a normal app, run ./scripts/make-app.sh and drag build/DeskCat.app into Applications.

In this preview the cat wanders out sooner than on the Mac (about 30 seconds instead of a few minutes), so you get to see it.
